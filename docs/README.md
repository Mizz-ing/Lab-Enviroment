# LabEnvironment

Laboratorio para el estudio de variables ambientales.

## Descripción

LabEnvironment es un laboratorio orientado a estudiantes escolares
que permite medir temperatura y humedad en distintos ambientes.

## Objetivo

Permitir que los estudiantes obtengan datos ambientales reales y puedan
compararlos y analizarlos mediante una interfaz web en tiempo real.

## Hardware

- ESP32
- Sensor DHT22
- Protoboard
- Cables Dupont

## Software

- Arduino IDE
- HTML
- CSS
- JavaScript
- Chart.js

## Arquitectura

DHT22 -> ESP32 -> Wi-Fi -> Smartphone -> Web App -> Gráficos y análisis

## Variables medidas

- Temperatura (°C)
- Humedad relativa (%)
